# Data access

## Included in the Git repository

- Optimization: all eight required input files, 105 configurations, per-seed metrics,
  configuration summaries, task status and Fig. 4/Fig. 5/SI source-data tables.
- Benchmark: Manual descriptors, fixed train/test and CV splits, saved parameter workbooks,
  metrics and merged test predictions.
- Oracle: reference membership and summary statistics.

The largest tracked file is an optimization feature matrix, below 25 MiB.

## Separate Release attachments

| Archive | Restored path | Purpose |
| --- | --- | --- |
| `cif_structures.zip` | `1-data_preprocessing/cifs/` | 7,532 CIFs and the CSD mapping workbook |
| `benchmark_features.zip` | `2-representation_benchmark/data/` | Four full embedding/hybrid matrices |
| `optimization_query_history.zip` | `4-repmobo_optimization/expected_outputs/` | Detailed historical query sequence |

These archives have been prepared locally for a private repository Release. They are not
yet assigned a public URL or DOI. Once uploaded, obtain them from the repository's **Releases**
page using an account with access. A source-code ZIP generated by GitHub does not include
separate Release attachments. Do not upload the ZIPs into ordinary Git history.

Place the downloaded ZIPs in the repository root, then run only the commands for the data
you need (extracting creates the module-relative folders):

```sh
python -m zipfile -e cif_structures.zip .
python -m zipfile -e benchmark_features.zip .
python -m zipfile -e optimization_query_history.zip .
```

Compare SHA256 values with `docs/release_assets.sha256`. On Windows use
`Get-FileHash -Algorithm SHA256 <archive>`; on Linux use `sha256sum <archive>`.
`docs/source_manifest.csv` additionally records each source file's checksum and distribution
location. Numeric input and result files are preserved byte-for-byte.

This separation follows GitHub's guidance to distribute large binary/data assets through
[Releases](https://docs.github.com/en/repositories/working-with-files/managing-large-files/about-large-files-on-github).
The author should confirm CSD/CIF and pretrained-representation redistribution terms before
making the repository or data public.
